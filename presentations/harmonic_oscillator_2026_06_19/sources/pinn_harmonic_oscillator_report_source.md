# 一维线性谐振子 PINN 项目学术汇报源稿

## 汇报定位

本 PPT 的核心不是泛泛介绍 PINN，而是解释当前程序实际做了什么、为什么这样做、结果如何，以及这些经验对后续处理 Dirac 方程相关问题有什么启示。论文和网页资料作为方法来源与理解背景，只点明关键影响，不喧宾夺主。

一句话主线：本项目把一维无量纲量子谐振子的定态薛定谔本征值问题转化为一个物理约束神经网络训练问题，通过边界参数化、宇称嵌入、归一化损失、正交损失、Rayleigh 能量约束和少量数据点约束，依次求得前三个本征态及其能量，并为后续更复杂的 Dirac 方程 PINN 建模提供了可迁移的程序框架。

## 术语统一

| 术语 | 含义 | 本项目中的用法 |
|---|---|---|
| PINN | Physics-Informed Neural Network | 用神经网络表示未知波函数，用方程残差与物理约束作为损失函数 |
| 本征值 | Eigenvalue | 量子定态中的能量 `E_n` |
| 本征函数 | Eigenfunction | 定态波函数 `psi_n(x)` |
| PDE residual | 方程残差 | 衡量网络输出是否满足定态薛定谔方程 |
| norm-loss | 归一化损失 | 防止零解，使 `integral psi^2 dx` 接近 1 |
| ortho-loss | 正交损失 | 防止重复找到同一低能态，使不同态两两正交 |
| parity embedding | 宇称嵌入 | 利用谐振子势函数为偶函数这一先验，直接限制输出为偶态或奇态 |
| data loss | 数据点约束 | 在少量已知位置上约束网络输出贴近给定波函数值 |

## 物理问题

程序求解的是无量纲一维线性谐振子定态薛定谔方程：

```text
[-1/2 d^2/dx^2 + 1/2 x^2] psi_n(x) = E_n psi_n(x),  x in [-L, L], L = 5
```

解析能级为：

```text
E_n = n + 1/2
```

因此前三个目标能级为 `E_0 = 0.5`、`E_1 = 1.5`、`E_2 = 2.5`。解析本征函数由 Hermite 多项式给出：

```text
psi_n(x) = 1 / (pi^(1/4) sqrt(2^n n!)) * H_n(x) * exp(-x^2/2)
```

这里选择谐振子作为项目对象，是因为它具有清晰解析解、明确宇称结构和标准量子归一化条件，适合作为 PINN 本征值求解程序的验证平台。

## 程序做了什么

程序文件为 `pinn_harmonic_oscillator/main.py`，它用 PyTorch 训练多个 `HarmonicOscillatorPINN` 模型，每个模型对应一个本征态。主流程为：

```text
固定随机种子与设备
  -> 生成 [-L, L] 内部配点
  -> 训练 n=0 态
  -> 保存 psi_0 作为后续正交约束
  -> 训练 n=1 态并约束其与 psi_0 正交
  -> 训练 n=2 态并约束其与 psi_0, psi_1 正交
  -> 输出能量、波函数、loss 曲线和 CSV 表格
```

程序输出包括：`predicted_energies.csv`、`predicted_wavefunctions.csv`、`training_data_points.csv`、多本征函数对比图、能级图和各态 loss 曲线。

## 网络如何表示波函数

神经网络输入位置 `x`，输出自由函数 `N_theta(x)`。程序不是直接把 `N_theta(x)` 当作波函数，而是把物理先验写入输出变换。

边界条件通过因子硬编码：

```text
psi_theta(x) = (1 - x^2/L^2) * N_sym(x)
```

当 `x = ±L` 时，边界因子为 0，因此自动满足 `psi(-L)=psi(L)=0`。这比只在损失函数中惩罚边界误差更稳定，因为边界条件在结构上恒成立。

宇称结构通过 `N(x)` 与 `N(-x)` 构造：

```text
偶态: N_sym(x) = [N(x) + N(-x)] / 2
奇态: N_sym(x) = x * [N(x) + N(-x)] / 2
```

谐振子势能 `V(x)=x^2/2` 是偶函数，因此本征函数具有确定宇称。程序用 `state_index` 控制当前模型学习偶态还是奇态，这缩小了函数搜索空间，也让 `n=0,1,2` 的训练逻辑更清晰。

## 损失函数设计

总损失为：

```text
L_total = L_pde
        + lambda_norm * L_norm
        + lambda_orth * L_orth
        + lambda_data * L_data
        + lambda_rayleigh * R[psi]
        + lambda_energy_match * L_energy_match
```

各项作用：

| 损失项 | 作用 | 解决的问题 |
|---|---|---|
| `L_pde` | 定态薛定谔方程残差 | 使波函数满足物理方程 |
| `L_norm` | `integral psi^2 dx -> 1` | 避免零解，满足概率解释 |
| `L_orth` | `integral psi_n psi_m dx -> 0` | 避免不同训练轮次重复收敛到低能态 |
| `L_data` | 五组数据点拟合 | 把少量观测/解析数据作为锚点 |
| `R[psi]` | Rayleigh 能量项 | 在当前可行空间中偏向最低可用能量态 |
| `L_energy_match` | 可训练能量与 Rayleigh 能量一致 | 稳定能量参数学习 |

能量不是固定答案，而是可训练参数 `E_raw` 经 `softplus` 得到：

```text
E = softplus(E_raw) > 0
```

## 改进流程

原始程序只求基态。当前版本保留原有类名和主要函数结构，在此基础上逐步增加功能：

1. 从单基态 PINN 扩展到多本征态顺序训练。
2. 加入 `state_index`，把偶/奇宇称写进网络输出结构。
3. 加入 `norm-loss`，避免本征值问题中的平凡零解。
4. 加入 `ortho-loss`，让新态远离已训练态，从而找到更高能级。
5. 加入 Rayleigh 能量项和能量匹配项，提高能量学习稳定性。
6. 加入五组数据点约束，形成“物理方程 + 数据点”的混合训练。
7. 完善输出：能级表、波函数数值表、训练数据点表、loss 曲线和对比图。

这个改进流程体现了一个可复用思路：先把物理方程作为残差，再把边界、归一化、正交性、对称性和少量数据逐步变成结构或损失项。

## 当前实验结果

程序默认求前三个本征态。根据 `predicted_energies.csv`，结果为：

| state | PINN 预测能量 | 解析能量 | 绝对误差 |
|---:|---:|---:|---:|
| `n=0` | 0.500158548 | 0.500000000 | 0.000158548 |
| `n=1` | 1.502323866 | 1.500000000 | 0.002323866 |
| `n=2` | 2.502612114 | 2.500000000 | 0.002612114 |

波函数误差来自 `predicted_wavefunctions.csv`：

| state | 最大绝对误差 | 平均绝对误差 | RMSE |
|---:|---:|---:|---:|
| `n=0` | 0.002898 | 0.001206 | 0.001433 |
| `n=1` | 0.017044 | 0.005645 | 0.007672 |
| `n=2` | 0.016999 | 0.007738 | 0.008922 |

这些结果说明程序已经学到了前三个谐振子本征态的能级结构和波函数形状。高激发态误差更大，符合直觉，因为更高能级的波函数节点更多、形状更复杂，对网络表达能力和训练稳定性要求更高。

## 训练数据点理解

当前程序启用了 `USE_DATA_LOSS=True`，并在 `DATA_MODE="random"` 下为每个本征态从解析解中抽取 5 个点。数据点不替代物理方程，而是作为少量锚点，帮助网络在局部位置与已知波函数值对齐。

这对后续应用有现实意义：如果某个量子问题没有完整解析解，但有少量数值解、实验数据或边界附近的可靠样本，程序结构可以把这些点自然加入训练目标。

## 论文理解

主要阅读材料是 *Physics-Informed Neural Networks for Quantum Eigenvalue Problems*。我对这篇论文的理解可以概括为四点：

1. 神经网络可以同时表示本征函数和本征值，本征值可作为可训练参数。
2. 边界条件最好通过参数化输出恒满足，而不是只靠惩罚项。
3. `norm-loss` 与 `ortho-loss` 是关键物理正则项，分别对应量子归一化与厄米算符本征函数正交性。
4. 对称性嵌入是结构性物理先验，可以减少搜索空间、改善收敛，但它依赖我们事先知道问题对称性。

本项目吸收了论文中的核心原则，但做了一个更适合入门和验证的谐振子版本：不用有限势阱或氢原子径向方程，而用具有解析解的线性谐振子检验多态求解、正交损失、宇称嵌入和数据点约束。

## 网页资料理解

网页资料主要作为论文之外的索引和实现参考：一方面帮助确认 PINN 量子本征值问题的公开代码、论文背景和方法关键词；另一方面帮助理解 PINN 在 Dirac 方程等更复杂问题中的常见叙述，例如自动微分可避免手写差分算子，时空 PINN 把解直接表示为可微的空间-时间函数，但代价是训练高维优化问题。

我的理解是：网页资料适合建立方向感和实现线索，真正决定程序结构的仍然是物理方程、边界条件和损失函数设计。做 PPT 时只需要提到“网页帮助确认方法脉络与后续方向”，不需要把网页内容展开成独立章节。

## Dirac 方程方向的启示

Dirac 方程相关内容不作为本 PPT 主体，只作为后续展望。当前谐振子项目给后续工作的启示是：

1. 先从可验证问题开始。谐振子有解析能级和解析波函数，因此适合检验 PINN 框架；Dirac 方程也应先选有解析解或高可信数值解的简单情形。
2. 方程残差需要按物理结构重写。谐振子是标量定态本征问题，Dirac 方程通常涉及旋量、多分量耦合和时间演化，残差要分别约束每个分量。
3. 边界条件不能照搬。谐振子的双端零边界因子 `(1-x^2/L^2)` 不一定适合 Dirac 问题，必须根据区域、初值条件、边界条件和守恒量重新设计。
4. 物理约束可以继续迁移。归一化、正交性、守恒律、初始条件、边界条件和对称性仍然是 PINN 稳定训练的关键，只是具体形式会改变。
5. 当前程序的模块化结构有价值。`model -> residual -> losses -> train -> evaluate -> export` 这一流程可以作为后续 Dirac PINN 的骨架。
