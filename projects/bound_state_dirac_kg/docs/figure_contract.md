# 图表约定

沿用项目 Python / Matplotlib 工作流。结论只依据实际运行：比较两模型的最低正能束缚态，
展示传统方法的一致性及 PINN 的精度和种子波动，不预设 PINN 更优。
形式为定量多面板；先呈现逐分量波函数，再呈现点误差、方程残差、训练曲线与参考收敛。
势阱和能级图明确 E 的零点及 ±m 阈值；KG 电荷密度明确 2(E−V)φ² 约定。
三种子全部显示，统计采用均值和样本标准差（ddof=1），不用三个种子推断总体置信区间。
导出白底 PNG（预览）、可编辑文字 SVG、矢量 PDF。尺寸每组约 180–190 mm 宽，字体 8–10 pt。
每幅图追溯至 results 下 CSV/NPZ，保留完整区间数据；局部放大须标轴范围。
交付前检查文字、图例、对数零值和面板遮挡。参考和 PINN 使用固定中性灰/蓝/橙/绿编码。
