# 公共单相位 CPA 直接迁移到 Dirac 方程的可证伪数值实验

## 摘要

本实验在一维自由 Dirac 方程上比较 Vanilla Dirac-PINN、公共单相位 SP-CPA、加入连续性/范数/能量约束的 SP-CPA-Conservative，以及显式硬编码正负能量载波的 Two-Branch oracle。所有正式 learned baseline 使用相同的 `float64`、4 层×64 宽 `tanh` 主体、每步 1024 个重采样配点和 5000 步 Adam；前三种模型在 seeds `{0,1,2}` 上运行，Two-Branch 按预注册的诊断预算使用 seed 0。

训练过程中没有根据中间结果修改参数；下文表格来自全部固定配置 run 的最终聚合。

## 1. 方程、区域与解析解

采用自然单位 `hbar=c=1`，在周期区域 `x in [-pi,pi]`、`t in [0,T]` 上求解

\[
i\psi_t=(-i\sigma_x\psi_x+m\sigma_z\psi),
\quad m=5,\quad k=2,\quad T=5,
\]

其中

\[
\sigma_x=\begin{pmatrix}0&1\\1&0\end{pmatrix},\qquad
\sigma_z=\begin{pmatrix}1&0\\0&-1\end{pmatrix}.
\]

对

\[
H_k=k\sigma_x+m\sigma_z
\]

使用 `torch.linalg.eigh` 得到规范正交本征旋量 `u_+`、`u_-`，并固定符号使 `u_+^dagger sigma_x u_->0`。数值为

\[
E=\sqrt{29}=5.385164807134504,
\]

\[
u_+=(0.9819563867,\ 0.1891075212)^T,
\quad
u_-=(-0.1891075212,\ 0.9819563867)^T.
\]

解析解为

\[
\psi_\eta(x,t)=\frac{e^{ikx}
\left[u_+e^{-iEt}+\eta u_-e^{+iEt}\right]}
{\sqrt{2\pi(1+\eta^2)}}.
\]

Case P 取 `eta=0`；Case M 取 `eta=1`。两者均有

\[
\rho=\psi^\dagger\psi=\frac{1}{2\pi},\qquad N(t)=1,
\]

而总能量为

\[
E_D=E\frac{1-\eta^2}{1+\eta^2}.
\]

当前本征矢规范下，Case M 的概率流为

\[
j(t)=\frac{m}{2\pi E}\cos(2Et),
\]

其角频率 `2E=10.770329614269007`，周期 `pi/E=0.5833791102228985`，振幅 `0.147771654900`。虽然 `j` 随时间快速振荡，但 `rho_t=0` 且 `j_x=0`，所以连续性残差严格为零。

## 2. 四种网络表示

所有 MLP 输入均为 `[sin(x), cos(x), t/T]`，从结构上精确周期。线性层全部 Xavier-normal 初始化、bias 为零。

### 2.1 Vanilla Dirac-PINN

\[
\hat\psi(x,t)=\psi_0(x)+\frac{t}{T}N_\theta(x,t),
\]

其中网络输出两个复分量的四个实数，初值严格满足。

### 2.2 SP-CPA

\[
\hat A=A_0+\frac{t}{T}N_A,\qquad
\hat S=kx+\frac{t}{T}N_S,\qquad
\hat\psi=\hat A e^{i\hat S}.
\]

`N_A` 输出四个实数，`N_S` 输出一个实数；共享同一个 MLP 主体。由于 `A` 是任意复二旋量，这个表示没有严格的容量障碍，而存在规范冗余 `A -> A exp(-i chi), S -> S+chi`。本实验检验的是：公共 `S` 在双载频下不能同时把 `exp(-iEt)` 和 `exp(+iEt)` 都变为慢变量，因而固定预算下的优化优势是否退化。

### 2.3 SP-CPA-Conservative

网络表示与 SP-CPA 相同，增加局部连续性、全局范数和全局能量损失。

### 2.4 Two-Branch oracle

\[
\hat\psi=e^{ikx}\left[
b_+u_+e^{-iEt}+b_-u_-e^{+iEt}
\right],
\]

并将 `b_+(0)=1/sqrt(2pi(1+eta^2))`、`b_-(0)=eta/sqrt(2pi(1+eta^2))` 硬编码。它包含正确的 `E,u_+,u_-` 和两个载波，零修正就是解析解，因此只用于诊断载波分解，不作为新方法或公平的可部署 baseline。

## 3. 损失、归一化与梯度诊断

所有模型使用同一个 Dirac 残差

\[
R_D=i\psi_t+i\sigma_x\psi_x-m\sigma_z\psi,
\quad L_{PDE}=\operatorname{mean}|R_D|^2.
\]

守恒模型另用

\[
C=\rho_t+j_x,
\quad
L_{cont}=\operatorname{mean}\left(\frac{C}{E\rho_0}\right)^2,
\]

\[
L_N=\operatorname{mean}(N-1)^2,
\quad
L_E=\operatorname{mean}\left(\frac{E_D(t)-E_D(0)}{E}\right)^2.
\]

Case M 的 `E_D(0)=0`，所以能量尺度始终取谱能量 `E`，没有除以零。主实验固定

\[
L=L_{PDE}+L_{struct},\qquad
L_{struct}=L_{cont}+L_N+L_E.
\]

每 250 步计算一次 `grad(L_PDE)` 与 `grad(L_struct)` 的余弦相似度；负值记为梯度冲突。

## 4. 固定实验配置与公平性

| 项目 | 固定值 |
|---|---:|
| `m,k,T` | `5,2,5` |
| dtype | `float64/complex128` |
| hidden layers × width | `4 × 64` |
| activation | `tanh` |
| collocation per step | `1024`, 每步重新采样 |
| optimizer | Adam, `lr=1e-3` |
| steps | `5000` |
| structure quadrature | 4 个随机时间 × 64 个 endpoint-free 均匀 x 点 |
| dense test grid | `201 × 128` (`t × x`) |
| main seeds | learned models `{0,1,2}`；Two-Branch `{0}` |
| `lambda_struct` main | `1` |
| sensitivity | Case M seed 0，`{0.1,1,10}` |
| 参数量 | Vanilla/Two-Branch `12,996`；SP-CPA variants `13,061` |

本机为 AMD Ryzen 7 4700U；PyTorch 2.12.0 为 CPU build，CUDA 不可用。为了降低墙钟时间，Case P、Case M、敏感性三个互不共享状态的进程各使用两个 CPU 线程并行运行；每个 run 的步数、配点和随机序列均未减少。由于 L-BFGS 是“如运行时间允许”的可选项，而 CPU-only Adam 正式实验已需数小时，本实验没有追加 L-BFGS。

同一 seed 下，模型初始化、配点和结构时间分别使用固定且独立的随机源；加入结构损失不会改变后续 PDE 配点序列。训练期间没有依据结果调整 `m,k,T`、网络、学习率、步数、采样量或权重。主参数已经产生可分辨差异，因此没有触发唯一预先允许的 `m=10,T=10` 压力测试。

### 4.1 结果判定规则

为避免只挑有利指标，正式结论按以下顺序判定：

1. SP-CPA 与 Vanilla 的主准确率指标是全时空旋量相对 L2；`fidelity_mean`、概率流和分支系数为独立佐证。Case P 的“有效/不差”要求 SP-CPA 的三 seed 平均旋量误差不高于 Vanilla；若只在次要指标改善，报告为混合证据。
2. 定义单相位相对收益 `G=(err_Vanilla-err_SP)/err_Vanilla`。若 `G_M<G_P`，则认为优势在混合分支下下降；若两者都失败且差异小，只能报告共同长时域失败，不能强归因为单相位。
3. 守恒模型与 SP-CPA 比较 `continuity_normalized_rms`、`max_norm_drift`、`max_abs_energy_drift` 三项；至少两项改善才称守恒总体改善。
4. 只有当守恒改善而旋量、流、相对相位或 fidelity 没有同步改善时，才将 learned-model 结果解释为守恒盲点；解析 wrong-phase 诊断独立证明盲方向存在，但不替代训练比较。
5. Two-Branch 必须同时在旋量、流、fidelity 和分支投影上显著更准，才支持“显式分支载波恢复精度”的诊断；它不进入 learned baseline 的公平排名。

## 5. 单元测试与解析验证

`pytest` 共 16 项，全部通过。

| 验证项 | 数值 |
|---|---:|
| 本征方程最大误差 | `8.88e-16` |
| 正交归一最大误差 | `2.22e-16` |
| 解析 Dirac PDE residual 最大绝对值 | `9.31e-16` |
| 解析连续性 residual 最大绝对值 | `3.89e-16` |
| 解析范数最大漂移 | `4.44e-16` |
| Case M 解析能量最大漂移 | `8.45e-16` |
| Case M 密度最大偏差 | `1.11e-16` |
| Case M 电流与解析公式最大误差 | `1.24e-15` |

额外构造一个不参与训练的机制诊断：仅给负能支乘上 `exp[i delta(t)]`，其中 `delta(t)=0.7 sin(0.9t)`。它保持同一硬初值，并得到：

| 指标 | 数值 |
|---|---:|
| 连续性最大绝对值 | `5.00e-16` |
| 范数最大漂移 | `4.44e-16` |
| 能量最大绝对漂移 | `1.24e-15` |
| 但概率流相对 L2 | `0.46978` |
| 但旋量相对 L2 | `0.33684` |
| PDE residual RMS | `0.09087` |

这直接验证了结构损失的盲方向：连续性只含 `j_x`，不含 `j_t`；范数和能量也不含两个正交能量分支的相对相位。只有 PDE 残差能固定该相位的时间演化。

## 7. 逐项回答研究问题

<!-- INTERPRETATION START -->
1. **Case P：SP-CPA 明显优于 Vanilla。** 三 seed 平均旋量误差由 `0.9228` 降至 `0.0067`，相对下降 `99.3%`；平均 fidelity 从 `0.4325` 升至 `0.999972`。SP-CPA-Conservative 仍保持高精度（spinor `0.0111`），并进一步降低 rho、j、连续性、范数和能量误差，但 spinor 略差于纯 SP-CPA。

2. **公共单相位优势在 Case M 大幅下降。** Vanilla 与 SP-CPA 的平均旋量误差分别为 `0.9452` 和 `0.7991`，相对收益只有 `15.5%`，远低于 Case P 的 `99.3%`；SP-CPA 的流误差仍为 `0.9392`、相对相位 RMSE `1.5864 rad`。它能表示目标解，但没有把两个相反时间载频同时变慢。

3. **主实验 lambda=1 只部分改善守恒。** 相对 SP-CPA，SP-CPA-Conservative 的 Case M 平均连续性 RMS 从 `0.0883` 降至 `0.0830`，最大范数漂移从 `0.8680` 降至 `0.5181`；但最大绝对能量漂移由 `1.3010` 恶化到 `2.7662`。因此不能声称主 lambda=1 让三项守恒量全部变好。

4. **守恒改善没有同步恢复相位、概率流或 fidelity。** lambda=1 的平均 spinor/j 误差反而为 `1.0785/1.0698`，平均 fidelity `0.1631`，相对相位 RMSE `1.7980 rad`，都差于纯 SP-CPA。更强的 lambda=10 把 seed-0 的连续性/范数/能量指标从 `0.0938/0.9955/0.5632` 改善到 `0.0653/0.0900/0.0701`，但 spinor/j 变为 `1.4492/1.0637`、fidelity 仅 `0.062512`。这与解析 wrong-phase 反例共同支持“守恒约束对分支相对相位不敏感”。

5. **Two-Branch 恢复混合支精度。** Case M oracle 的 spinor/j 误差为 `0.0062/0.0105`、fidelity `0.999990`、相对相位 RMSE `0.0029 rad`；spinor 误差约比 SP-CPA 小 `128` 倍。这把主要困难定位到载波/分支预条件，而不是解析解、AD residual 或测试指标实现。

6. **共同失败模式必须单独说明。** Vanilla 在 P/M 两个 case 都出现远离 t=0 的振幅衰减，最大范数漂移约 `0.9989/0.9987`；Case M 的总能量本来为零，所以振幅坍缩仍可给出很小能量漂移。低 PDE loss 或小 Case-M 能量漂移本身都不是正确解的证据。
<!-- INTERPRETATION END -->

## 8. 是否支持原假设

<!-- HYPOTHESIS_DECISION START -->
**结论：在“固定预算下的载波解调/优化优势”意义上，核心假设得到支持；在“公共单相位加复振幅无法表示混合态”的字面意义上，假设不成立。**

- 支持证据：SP-CPA 相对 Vanilla 的旋量误差收益从 Case P 的 `99.3%` 降到 Case M 的 `15.5%`；Two-Branch 在 Case M 恢复约两个数量级的 spinor/current 精度；Case M 的 PDE/结构梯度平均余弦为 `-0.529`，冲突比例 `88.9%`。
- 守恒结论需限定：主 lambda=1 改善连续性与范数但恶化能量；敏感性 lambda=10 才同时显著改善三类守恒指标，而 spinor、相对相位、概率流和 fidelity 并未改善。这比“守恒损失总能变得很小”更细致，也更符合实际结果。
- 机制边界：`A` 是任意复旋量，所以 `A exp(iS)` 仍具有完整表示能力；观察到的是有限网络、归一化时间输入和 5000-step Adam 下的优化/归纳偏置退化，不是数学不可能。
<!-- HYPOTHESIS_DECISION END -->

## 9. 本实验不能推出的结论

1. 不能推出 SP-CPA 在数学上无法表示正负能量混合；任意复旋量 `A` 仍可吸收剩余相位。
2. 不能推出充分训练、因果采样、不同优化器或更大网络下仍保持同样排序；结论限定于固定的 4×64、5000-step Adam 预算。
3. 不能把 Two-Branch 的优势解释为一般可部署方法优越，因为它使用了解析谱信息和正确载波。
4. 不能从自由、单一空间动量平面波外推到势场、波包、散射或多维 Dirac 系统。
5. 不能从 seed-0 的 `lambda` 敏感性或 Two-Branch 结果估计总体不确定性。
6. 如果 learned baselines 共同出现远离初值的振幅衰减，本实验只能将其报告为长时域 PINN 的共同优化失败，不能全部归因于公共单相位。

## 10. 下一步研究价值

<!-- NEXT_STEPS START -->
值得继续研究正负能量分支感知或特征通道化的 Dirac-PINN，但下一步应把“oracle 载波”逐渐降为可学习结构，而不是直接宣称 Two-Branch 已是通用方法：

1. 用可学习的正/负能投影通道、局部色散或双时间 Fourier feature 代替硬编码的 `E,u_+,u_-`，并与参数量匹配的双通道 baseline 比较。
2. 先控制本实验暴露的长时域振幅坍缩：比较 causal/时间推进采样、分段时间窗、归一化硬约束和不含相位分解的 Fourier-time PINN；否则一般 PINN 失败会混入载波结论。
3. 对 lambda 敏感性和 Two-Branch 扩展到至少三个 seed，并报告 Pareto 前沿，而不是寻找单个“最好 lambda”。
4. 从单 k 平面波扩展到含多个 k 的波包、外势和散射；此时需要检验局部正负能分支定义是否稳定，以及通道耦合是否破坏优势。
5. 显式处理 SP-CPA 的规范冗余，可加入 gauge fixing 或幅度慢变正则，再验证“公共相位”是否真的承担载波解调，而不是由复振幅吸收全部相位。
