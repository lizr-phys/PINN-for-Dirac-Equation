# R7 理论核查：局部切向、残差估计与结论边界

## 符号与单位

| 符号 | 定义与约定 | 自然单位 |
| --- | --- | --- |
| $\mathcal H$ | 有限动量梯级的块三对角 Hermitian Hamiltonian；外势为 $V_0\cos(qx)I_2$ | 能量 |
| $\widetilde\psi_j,c_{j,\pm}$ | Fourier 规范 $L^{-1/2}\sum_j e^{ik_jx}\widetilde\psi_j$ 下的旋量和自由基底系数 | 概率幅；$\sum|c|^2=1$ |
| $r,b,\tau$ | 实网络输出、相位输出、$t/T_{gate}$；短诊断 $T_{gate}=5$ | 无量纲、rad、无量纲 |
| $R,e$ | $i\partial_t\widehat\psi-\mathcal H\widehat\psi$，$e=\widehat\psi-\psi$ | 幅×能量、幅 |
| $\ell_i,\ell_{scale}$ | 分量均值、模态求和除 L 的残差平方；$m^2/(2L)$ | 能量平方/长度 |

## 推导链审查

空初值原式为 $c(t)=t r(t)e^{itb(t)/T}/T$。光滑有限 $r,b$ 给出 $c'(0)=r(0)/T$，虚部为零。相位参数对该虚部初始导数的敏感度也严格为零。该结论只在所选实能支规范和当前相位门下成立。

修正版为 $c(t)=t r(t)e^{ib(t)}/T$，同样严格满足 $c(0)=0$，但 $c'(0)=r(0)e^{ib(0)}/T$。输出坐标到复导数实、虚部的 Jacobian 是

$$D_{(r,b)}(\Re c',\Im c')=\frac1T\begin{pmatrix}\cos b&-r\sin b\\\sin b&r\cos b\end{pmatrix},\qquad\det D=r/T^2.$$

所以 $r\ne0$ 时可提供两个独立输出坐标方向；$r=0$ 时秩降为 1。它并不自动证明共享 MLP 的参数 Jacobian 在所有初始化均满秩，也不证明优化已学出所需导数。自动微分应分别检查坐标秩、参数敏感度、训练后实际误差。

对侧带 $j=\pm1$，初态为零使自身自由项消失，另一初始空邻居也为零，故 $i\widetilde\psi'_{\pm1}(0)=(V_0/2)\widetilde\psi_0(0)$。投影到实正交 $u_s(k_{\pm1})$ 后，$c'_{\pm1,s}(0)=-i(V_0/2)u_s(k_{\pm1})^T\widetilde\psi_0(0)$。系数为纯虚，可由修正版以适当有符号 r 和相位 b 表达。PDE 推出的导数只用于诊断，不能成为额外训练标签。

## 残差误差估计

令参考精确解满足 $i\psi'=\mathcal H\psi$，则 $ie'=\mathcal He+R$。常数 Hermitian $\mathcal H$ 的 $U(t)=e^{-i\mathcal Ht}$ 是 unitary，Duhamel 给出

$$e(t)=U(t)e(0)-i\int_0^t U(t-s)R(s)ds,$$
$$\|e(t)\|_2\le\|e(0)\|_2+\int_0^t\|R(s)\|_2ds.$$

单位通过：能量×时间无量纲。估计使用全保留梯级、未加权的连续时间残差范数，不能用训练时归一化或因果加权 loss 直接替代。附加空间泄漏是有限梯级重建对无限周期 PDE 的缺陷，另报，不在此有限系统估计中隐去。

raw 场硬初值下 $e(0)$ 为机器误差。若先乘全局规范相位，初始误差项会改变，故积分估计与 raw 场比较。数值采用 4001/2001 嵌套时间网格检验收敛，保存实际误差与估计；这不是对连续积分的严格认证。

端点导数不匹配不能直接给出全时间 L2 下界，因为网络可产生很窄的初始层；初始点本身测度为零。旧表示即便有局部缺陷，也不能凭此排除长期 L2 逼近。修正版解除一阶切向限制，同样不能保证更高阶导数、后续零点相位或长期优化良好。

## 假设、可验证性与修改边界

假设是有限平滑 tanh 输出、固定实自由基底、恒定 Hermitian 截断 Hamiltonian、初始支持已知，以及同预算配对初始化/采样。自由基底不是完整耦合 Hamiltonian 的本征态。局部检验对应硬初值、Jacobian、侧带导数和有限梯度；全局检验对应占据、相干、主旋量和流的预注册条件。

优先风险：把局部修复写成全场成功；把小加权 loss 写成未加权小残差；把自由基底标签误当外势能级；用预测为零删掉参考活跃通道。这些均由独立诊断、mask、固定判据和报告证据表控制。无待授权的物理参数修改。
