# R11 理论核查与归因边界

物理和初态沿用 R9。自由本征旋量构成已知正交基 U_n，不等于外势完整算符的本征态。令 F_n=U_n diag(p_n)，d_n=c0_n+(t/5)z_n，完整残差恒等为

R_n=iF_n ḋ_n+(iḞ_n-H_n F_n)d_n−0.1(F_{n−8}d_{n−8}+F_{n+8}d_{n+8})。

p=exp[i(t/5)qθ] 和 p(0)=1，故所有组严格同初态。时间链式导数 ċ=ṗd+p(z/5+τż)；冻结仅改变参数更新，不消去 ṗ 或缺陷 G=iḞ−HF。C 同时对 p、ṗ 及 d、ḋ 的参数图求梯度，没有detach或无梯度前向。D 两网络输出和除以√2，沿用R9的尺度。E 由自由算符计算精确p，G仅剩浮点误差，仍训练原完整耦合旋量残差而非独立对角能支方程。

对于单位模p和Hermitian H，F†G 为 Hermitian，因此缺陷的直接总范数投影 2ImΣψ†Gd=0。势耦合的全局直接范数投影也为零。近似载波影响包络优化，并不能由小范数漂移推断载波精确，或者把范数失败唯一归为载波缺陷。完整R满足 Ṅ=2ImΣψ†R。保存4001点数值积分与直接N(t)对照，明确数值积分非严格连续认证。

参考截断收敛与优化失败分别判断：参考通过但某模型不通过，是既定训练流程在预算内没有达到标准；并非该表示数学不可表示。预测的两端占据和截断外残差可揭示预测泄漏，不能用PINN失败重新选择参考截断。

预训练后的 A/B 同耦合20000步比较在相同冻结策略、相同包络初始化及时间序列下比较载波权重来源，支持辅助预训练的流程效应，但包含获得权重的实际成本。A/C 同时涉及预训练和冻结，不能声称单因素冻结结论；随机 B/C 对照只能解释从头状态下允许载波更新的效应。A/D 可检验总容量解释，仍有活动参数差。A/E 能诊断更准确自由坐标的收益，不能将整体误差差值加性分解为纯载波误差，E也不证明学习色散能力。

主要误差仅用一个全时空常数规范。相干不需要额外规范对齐，参考活跃mask不由预测决定。高斯初谱已宽，初始支持内的非中心模态不是新侧带。已知算符、有限Fourier基、原始初谱以及辅助单位IVP都是物理先验，论证范围不得超过它们。
