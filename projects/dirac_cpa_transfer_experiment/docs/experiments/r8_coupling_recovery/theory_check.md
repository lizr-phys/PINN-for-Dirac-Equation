# R8 理论、硬初值与梯度核查

## 符号与自然单位

| 符号 | 意义 | 量纲/约定 |
| --- | --- | --- |
| k,m,V0 | 波数、质量、电势幅值 | 时间⁻¹；ħ=c=1 |
| u±(k) | H(k)=kσx+mσz的自由实正交基 | 无量纲；不含完整外势本征演化 |
| c,ψ̃ | 正交Fourier归一谱系数 | 归一总范数Σ||ψ̃||²=1 |
| p | 预训练单位模载波 | p(0)=1，实际相位由网络学得 |
| a,b,χ | 可学习复包络两实部、旋量修正 | c同量纲；V0t无量纲 |
| τ,s,Δ | 归一时间、窗起点、窗宽 | τ=(t−s)/Δ无量纲 |
| R | 完整耦合旋量残差 | ψ̃/时间 |

## 推导链与检查

A全区间：c=p(c0+τz)，所以c(0)=c0且c′=p′(c0+τz)+p(z/T+τz′)。冻结参数只设置requires_grad=False，不detach p或包裹no_grad，因而完整残差包含p′。单位模条件不等于载波精确；不可省略i p′u−H(pu)乘包络的缺陷项。

对于空通道，A的c′(0)=z(0)/T，可有非零虚方向，Jacobian为diag(1/T,1/T)。B的修正导数为V0χ(0)，同样允许任意复方向。所需侧带导数由PDE而非参考标签给出−i(V0/2)ψ̃0。诊断可以比较，但不能把此导数加入训练监督。

B：ψ̃=ψ̃free,learned+V0tχ，t=0修正严格为零，初值靠learned free的p(0)=1保证。R必须对二者整体求导，并保留自由近似缺陷与作用在自由部分和修正上的邻居耦合。主问题V0T=1，V0t与τ相同，不由该尺度本身提供新的自由度。

窗内A：c=p(t)/p(s)[c_s+((t−s)/Δ)z]。p(s)是该窗常数，不对当前输入t求导；p(t)仍求导。p(s)单位模非零，不存在除零。c(s)=c_s。末态只由前窗预测投影得到，不作参考重置。传递误差不能因每窗硬初值而消失。

窗内R7释放：若c_s非零，c=(|c_s|+τr)exp[i(arg(c_s)+τq)]；若c_s=0，c=τr exp[iq]。两式均硬满足复初值。空支c′=r exp(iq)/Δ；坐标Jacobian行列式r/Δ²，所以r=0仍病态。初始空相位无物理定义；参量方向可优化与相位物理可辨识不同。

窗口场连续；时间导数可在边界跳变。连续场的分布导数不产生delta项，分片强残差在几乎处处合法。但须保存交接连续误差并分片评价，不能漏掉窗口边界附近误差。所有窗口网络同时存储提高表示容量，单因子训练解释须附同窗口Complex和同载波不同训练对照。

## 残差积分估计

令e=ψ̃hat−ψ̃ref，有限截断Hermitian H使i e′=H e+R。由酉传播Duhamel公式，||e(t)||≤||e(0)||+∫₀ᵗ||R(s)||ds。适用于连续分片可微预测；边界不连续时还需加跳跃项。本实验要求交接机器精度连续并保存最大跳跃。主误差允许一项常数规范，但误差估计必须使用raw场，不逐点对齐。

Parseval：物理均方残差为Σj||Rj||²/(2L)，包括旋量分量平均；有限梯级外的V0/2边缘项另计。因此小平均损失不必意味着有限T内0.1精度。4001/2001积分是数值估计，不是严格连续证书。

## 风险和可检验性

已知自由基底和动量梯级是先验；外势完整动力学不对角。自由载波预训练不是精确oracle，但提供额外网络和训练开销，需记录。复包络可重新承载相位修正，不等于强制慢包络。窗口减少每窗振荡同时增加网络容量；交接积累误差和小初幅通道共享梯度病态可能仍存在。成功须联合旋量/概率流/模态占据/范数/fidelity，另检查侧带复系数和相干关系，不根据密度或损失推断。
