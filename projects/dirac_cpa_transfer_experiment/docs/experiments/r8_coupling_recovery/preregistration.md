# R8 耦合动力学恢复实验预注册

日期：2026-10-01。实验 ID：`r8_coupling_recovery`。本文件和正式科学代码在所有探索训练前冻结，SHA-256 由独立清单记录。未将探索视为独立验证；所有失败、种子和最后检查点完整保留。

## 1. 研究问题与继承口径

R6/R7 已指出：原 LTPB 与相位释放 LTPB 都接近不生成侧带的自由中心演化。R8 检验可学习自由载波、复杂耦合包络、自由解加修正，以及硬交接时间窗是否恢复完整动力学。局部梯度方向可用不等于全程求解成功。

主物理问题严格继承已获授权的 R6/R7：L=16π，m=5，k0=2，q=1，V0=0.2，T=5，J=6，13 个模态。仅中心初态为 (u+ + u−)/√2。使用自由符号基底，但训练残差为完整耦合旋量方程，截断外邻居为零；物理残差评价另计边缘泄漏。参考由块 Hermitian Hamiltonian 的本征演化得到，独立矩阵指数核验。

主旋量误差只消去一个全时空常数相位，另存 raw error；不逐模态/时间对齐。Nx=256、Nt=201；ρ=ψ†ψ、j=ψ†σxψ。参考占据≥10⁻⁶ 才评价物理相位/相干，预测相位另需占据≥10⁻¹²；保存 mask，塌缩预测不从相干误差中删除。

## 2. 六个探索配置

统一 MLP：4×64 tanh，双精度。包络/修正/普通模型输入 ((k−k0)/(Jq), local t/Δt)，4 实输出；自由载波为同宽深共享网络，2 实相位输出，p=exp[i(t/T)qθ(k,t/T)]，p(0)=1，单位模不衰减。

自由载波预训练将每个 k 的正、负本征旋量分别作为单位非零初态，各自计算 i∂t(pu)−H(k)(pu)。不合并成可能相消的同一个初态，不改写为含 E 的对角方程。载波参数冻结后仍保留 p 的时间图；耦合损失对完整预测求导，包含自由载波的近似误差。

| ID | 表示 | 训练方式 |
| --- | --- | --- |
| A_carrier_complex | c=p[c0+(t/T)(a+ib)] | 全区间 |
| B_free_correction | ψ=ψfree,learned+V0 t χ，χ 为原始双分量复旋量 | 全区间 |
| C_release_windows | R7 相位释放，推广到复数交接初值 | 十个等长窗口 |
| D_carrier_windows | A；窗内 p(t)/p(tstart)，包络初值为上一窗预测 | 十个等长窗口 |
| complex | c=c0+(t/T)(a+ib) | 全区间，重新训练 |
| phase_release | R7 相位释放 | 全区间，重新训练 |

窗口极坐标初值 c0 用 |c0| 与 arg(c0) 精确表示；非零通道相位增量为 local τ q，严格零通道为 q。支持判定只根据该窗已知的预测交接初态，**不用幅值阈值、动态切换或参考末态**。允许带符号实振幅。窗口 c0 为前窗末态投影、detach 后固定；不归一化、不修正相位、不用参考解重置。

B 在主问题 V0 T=1 时 V0 t=t/T，不能将主实验收益归于一个改变了数值尺度的门控；检验的主要因素是先学习并分离自由部分。精确载波仅在后评价中使用；本轮没有精确 oracle 训练排名。

## 3. 预算、随机流与固定检查点

探索：seeds={0,1,2}，六配置共18 runs，每 run **10000** 步。A/B/D=3000自由预训练+7000耦合；D 每窗700步；C每窗1000步；普通对照10000耦合步。

验证：最多两个候选，加两个重训对照；seeds={100,101,102,103,104}，与探索及 R6/R7 不同的初始化随机流。每 run **20000** 步。带载波方案=6000预训练+14000耦合；D每窗1400步；C每窗2000步；普通对照20000耦合步。没有按某个模型追加预算。

优化器全部 Adam lr=0.001，不早停、不改学习率、不挑最佳 checkpoint。每步重新采样32个排序均匀时间，与全部模态作笛卡尔积。时间窗采用相同归一化随机数再映射到当前窗口。free time seed=910000+s，coupled time seed=920000+s，与初始化独立；包络初始化800000+s，载波900000+s，窗口初始化再加10000w。形状相同的网络权重逐元素配对。不同预训练预算的模型共享耦合序列公共前缀，不能声称所有配置拥有完全相同的物理时间点。

总步数包含预训练。自由预训练每步32×13×2个单位分支旋量残差；耦合每步32×13个双分量旋量残差。记录两种计数与复数标量分量计数、优化时间、评价时间、peak RSS。CPU单线程，三独立核并发、按seed轮换核。完整保存全部窗口网络，报告当前活动可训练参数、冻结载波参数、最终存储总参数。单窗包络12932、载波12802；多窗约10倍包络参数，不能把时间窗全部收益仅归为优化顺序。

每250步保存模型、Adam、两随机流、全历史及恢复状态；中断只允许精确恢复，不从观察到的精度重启。最终评价固定采用step10000或20000，副产物先落盘后发布metrics。预训练和窗口交接状态保留。Smoke：每配置40步（载波10+耦合30；其余40），只查初值、导数、有限梯度、NaN和落盘，不用于超参筛选。

## 4. 预定筛选与独立成功判据

在全部18次探索完成后，仅对A–D计算

Q=mean_seed[(spinor/0.10 + current/0.15 + first-sideband complex-coefficient error/0.10)/3]。

侧带复系数误差采用同一个主全局相位和两个第一侧带的所有正负分支，不对侧带独立对齐。Q从小到大选最多2个，平局按A,B,C,D顺序；不按最好种子、不按训练loss选。即使探索绝对条件失败，保留排名并完成所选候选独立验证，不将小样本筛选包装成成功。

正式成功完全继承R7：五种子均值spinor≤0.10，current≤0.15，fidelity≥0.98，modal-population≤0.10，max-norm-drift≤0.02，且至少4/5 seeds联合满足五项。探索均值门槛同值、联合通过≥2/3只作标记，不替代正式检验。报告实际误差比、逐seed配对差、population SD(ddof=0)，不作小样本总体显著性声明。

额外诊断：中心/±1侧带占据轨迹与复系数、参考有效相干、梯度范数、未加权分模态/分时段残差、4001/2001嵌套积分。raw误差估计为 ||e0||+∫||R||dt；数值积分不是连续认证，不能用加权训练loss代替。

## 5. 条件分支：成功消融与扩展；全部失败的唯一救援

若正式候选成功，做对应最小消融，固定同验证seeds、20000总步：A→A_identity_carrier（预训练成本相同但前向p=1）；B→B_static_free（预训练同成本但仅用静态初态作基底）；C→window_complex（同十窗口/相同参数量/预算）；D→D_identity_carrier（同预训练/窗口成本但p比值=1）。D成功且A未进入正式验证时，另做A五种子同预算，以分离窗训练效果。移除载波的消融仍保存已经训练却不进入预测的载波，明确报告闲置成本。

所有正式成功候选，以及普通Complex对照，在T=8,V0=.2；T=5,V0=.1；T=5,V0=.4；自由高斯波包回归四个独立算例，使用新seeds={200,201,202}，每次20000总步。扩展是n=3范围诊断，不冒充n=5主验证。T8仍十等长窗口，不调整为别的窗口数。

参考截断在网络训练前按J=6,8,10,12,14顺序比较J/J+2，选首个同时满足边缘总占据<1e−8、零填充复轨迹relativeL2<1e−6及机器精度参考核验的J；主问题必须J6通过，不按PINN结果改J。高斯回归保留R5的33个k=n/8、σk=.5、两支等权的归一初谱，外部模态初值为零；V0=0不产生截断外耦合。与零填充更宽自由Hamiltonian检查。该回归不证明未知谱或任意外势有效。

若两个正式候选都失败，**仅追加一组探索性残差平衡**：在已正式验证候选中按同Q选误差最低者，探索seeds0–2，每次10000步，结构/预训练/优化器/采样完全不变。唯一因素为各模态残差权重：EMA_j←.99EMA_j+.01mean_t power_j，EMA初值1；w=1/(EMA+1e−8)，除以均值、夹到[.1,10]、再归一；权重stop-gradient。保留未加权残差和全部权重；与原18次中该配置同seed同预算作单因素配对，不额外训练其他救援，不以救援小样本声称独立成功。不启动成功扩展条件分支。
