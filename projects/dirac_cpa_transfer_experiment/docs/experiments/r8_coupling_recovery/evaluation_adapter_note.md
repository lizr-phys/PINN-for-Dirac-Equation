# R8 自由波包回归评价兼容修复记录

在正式训练后的自由波包回归中，`A_carrier_complex / seed 200` 已完成固定
20,000 步并保存最终权重，却在历史评价器的“空侧带初始导数相对误差”处报错。
该旧诊断假定只占据中心模态且 V₀≠0；自由高斯回归的 V₀=0，并非空侧带初态。
因此其目标为零且相对误差没有定义。冻结的 R8 评价器本来已规定在 free_packet
中删除这些诊断，但删除发生在旧函数返回之后，来不及避免异常。

新增的、冻结后明确标记的评价适配器只跳过这个不适用的局部诊断；仅允许作用于
预注册的 V₀=0、free_packet、extension 运行。完整 PDE、网络、优化器、参数、
配点、预算、参考解和所有主评价指标仍调用原冻结代码，没有修改。
未完成的其余自由波包回归统一使用该适配器，不按结果选择运行。

seed 200 从已经完成的最终检查点恢复评价，不增加任何优化步。首次报错日志、
最终检查点和恢复状态保留在原目录及 evaluation_failure_preserved 子目录。
适配器对恢复前后所有模型张量计算 SHA-256，并核验步数与训练耗时完全一致；
每个自由回归运行保存 evaluation_adapter_record.json。该项工程兼容修复须在
最终报告和审计中披露，不能描述为“冻结后零变更”。冻结科学文件保持原哈希。
