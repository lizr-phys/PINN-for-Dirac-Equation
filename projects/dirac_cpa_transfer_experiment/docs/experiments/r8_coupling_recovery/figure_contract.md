# R8 图表证据契约

Python/matplotlib沿用已验证代码工作流；不使用R替代。图服从证据，不预设结果成功。PNG≥300dpi，可编辑SVG(text保留)、TrueType PDF；每图全部源CSV及SHA-256，最终逐图PNG与PDF渲染视觉核验。

| 图 | 结论/证据任务 | 主要风险与约束 |
| --- | --- | --- |
| 01 exploration | 六配置全部3seed联合精度，显示冻结筛选Q | 不把筛选误差作独立验证 |
| 02 validation | 候选与控制全部5新seed、均值±population SD、绝对阈值 | 不挑seed、不用SEM |
| 03 modal_dynamics | 参考/预测/绝对误差热图和中心±1轨迹 | 固定seed100，共用占据色标，不隐去超范围 |
| 04 branch_coherence | 侧带复系数和参考活跃相干关系是否正确 | 使用已保存mask；零振幅不解释相位 |
| 05 density_current | 参考/各候选预测/误差时空 | 固定seed100；ρ与j独立共同尺度 |
| 06 carrier_gradient | 载波精度、保留的时间导数、梯度与分模态残差 | carrier误差只作后评价，不当监督 |
| 07 residual_bound | raw误差与未加权积分估计、模态残差热点 | 数值估计非严格认证 |
| 08 learning_cost | 全seed训练曲线、时间、内存、参数/残差点成本 | 总预算含预训练，窗口存储容量明示 |
| 09 ablation_or_rescue | 成功最小消融或唯一失败救援 | 标明条件分支，救援仅探索性 |
| 10 extensions | T8、两外势、自由波包全部3新seed及范围 | 仅成功触发；未触发必须写明，无伪造图 |

定量grid和场图+定量混合布局；白底，克制方法色，误差连续色图，所有轴给物理变量/单位。图例列实际n、SD口径、是否探索/验证；log误差棒跨零时用散点与均值SD单独表述或symlog，不伪造截断下限。图QA检查标题/字形/重叠/裁切/色标/所有种子/原始数据可追溯。正式结果之后只允许绘图排版与审计改动，不改冻结科学代码/阈值。
