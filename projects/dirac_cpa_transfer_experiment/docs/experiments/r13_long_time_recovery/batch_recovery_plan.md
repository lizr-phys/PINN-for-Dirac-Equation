# R13 资源与可恢复批次

资源估算见 raw/cost_estimate.json：使用R12对应算例6000/20000步实测耗时；桥接用m5T5的同模态工作量代理；修复耦合估计附25%开销。估算不能改固定预算。最多41个唯一自由来源、66个唯一耦合run，1,566,000个优化步，9,335,424,000个单位旋量残差点（复分量数为其两倍）。磁盘预留25 GiB，评价和落盘另计。

探索依次桥接→自由载波→E包络→T10四组消融，seeds600–602各一个长期worker，在三个不同物理核心串行执行自己的旋转组序。独立验证seeds700–704各一个worker，在五个不同物理核心执行两条件；控制进程占另一物理核心。每worker torch/OMP/MKL/OpenBLAS各1线程。启动前校验物理核心掩码两两不重叠，每worker再验证实际OS affinity。禁止R8曾披露的按seed索引导致重复占核的调度。

每500步保存Adam状态、全部权重、私有时间采样状态与完整轨迹、Python/numpy/torch RNG、损失历史、累计成本、已完成预定评价列表；carrier固定1000/3000/6000、coupled固定5000/10000/15000/20000。最终终点保存六件套、恢复状态及阶段耗时。精确断点续跑的权重/Adam/下一次采样与连续运行逐元素比较。

同阶段同seed共享自由来源时明确pretrain_source路径与SHA-256。实际实验总成本只计来源一次；算法成本曲线为独立运行该算法完整流程的归属成本，必须包含来源全部6000步。验证来源不继承600–602权重。E的预训练开销为零，但含解析自由算符先验。

驱动器按阶段自动等待、写不可变选择决策、进入下一批，完成后自动统计/作图/报告/审计。未完成文件不会被当终点。正式launch检查是否已有活跃驱动器或worker，避免重叠；status用真实进程状态而非旧RUNNING字样判断中断。外部终止则保留旧runtime_plan副本，使用同formal入口按exact recovery继续。不保证桌面应用关闭或操作系统终止后后台进程仍存活。

数值失败写failure.json/failed_state.pt、保留成功步与失败采样；不按精度选择性重置。依赖载波失败的耦合run标DEPENDENCY_FAILED。没有达到固定预算的终点不能列作完成。工程异常停止阶段等待诊断，不能静默换科学代码；所有科学文件已在formal前冻结。

长期断点之间被外部杀死的未落盘步需要重放，已落盘训练成本不包含该丢失片段；runtime历史和日志可识别此限制。不能把并发墙钟、累计绑定单核时间或推算FLOPs混为隔离硬件速度提升。
