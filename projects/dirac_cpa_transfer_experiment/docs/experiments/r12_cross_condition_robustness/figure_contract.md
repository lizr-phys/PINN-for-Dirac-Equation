# R12 图表契约（正式结果前固定）

使用现有 Python/matplotlib 科学作图；PNG/SVG/PDF 同源导出、每图 source CSV、FIGURE_QA，所有轴单位、刻度、色条、图例可读。population SD(ddof0)表示五初始化种子离散，不当作置信区间。参考为独立矩阵演化。所有失败种子保留。

| 图 | 结论/证据 | 固定数据选择 | 主要审查风险 |
| --- | --- | --- | --- |
| primary_metrics_final | 各算例五项绝对判定与连续误差 | 4算例×4组×5种子，固定最终 | 不用跨算例平均或藏失败；保真度轴明示 |
| primary_metrics_coupled_20000 | 同耦合预算的误差 | 同上20000；A与final同快照 | 不称同总成本 |
| paired_differences | A/C/D/E实际配对效果 | 全五种子两终点 | 不新增倍数门槛，A/C非单因素冻结消融 |
| error_vs_total_cost | 精度与预训练在内的实际成本 | 全380固定点，分算例 | E单列解析先验；墙钟不声称隔离硬件加速 |
| error_vs_residual_work | 相同工作定义下的误差 | 全380点 | 辅助两个单位分支计数；活动参数仍不同 |
| norm_coherence_support | 守恒、相干及新增支持 | 全种子终点时间轨迹 | 相干参考mask，塌缩不剔除；初始支持n0…32 |

| carrier_residual_diagnostics | 载波缺陷与完整残差的区别 | 全种子最终 | C载波不唯一；积分不是连续认证 |
| dynamics_CASE_seed500 | 相同预定种子的真实密度/概率流 | 每算例seed500，参考与4组 | 不换最好seed；统一参考共享色标，误差另色标 |
