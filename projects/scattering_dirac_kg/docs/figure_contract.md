# 图表约定

后端：沿用现有 Python/Matplotlib 科研工作流。全部图来自真实 CSV/NPZ，不生成示意结果。PNG 预览、SVG 可编辑文字、PDF 矢量导出；白底、色盲友好蓝橙、报告双栏尺寸约 183 mm，面板标签和数据来源进入清单。

| 图 | 科学问题/证据 | 统计与风险 |
|---|---|---|
| R(E)、T(E) | 参考确认模型差异及条件网络拟合 | 显示训练能量；小 R 用绝对误差；极值不称复能共振 |
| 相位(E) | 固定入射约定下相位比较 | t 连续展开；r 幅度<10⁻⁵ 屏蔽；相位误差为模 2π 距离 |
| 复波函数逐分量 | 四指定能量及三种子的波形准确性 | Dirac 上下分量实虚部分开；不作事后整体相位拟合 |
| 误差分布 | 全部正式与失败样本稳健性 | 全部种子散点，均值及样本 SD，n=3，不作显著性宣称 |
| 局部流 | j(x) 的空间变化与通量比 | 守恒只是辅助证据，边界硬约束不算独立成功 |
| 训练曲线与成本 | 残差下降和全扫描成本 | 说明直接线性求解的残差细化轨迹；若有 MLP，分列迭代曲线 |
| 参考收敛 | 区间、容差、网格与独立 BVP 的误差量级 | 数值一致性不称严格误差上界 |
