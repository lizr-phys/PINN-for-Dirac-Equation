# 执行协议

2026-10-04。顺序：理论核对 → Jost/BVP/解析参考验证 → 单能量物理损失试运行 → 冻结协议、四能量各三种子 → 验收门通过后条件网络与能量扫描 → 独立评价、图表、中文报告、保留审计。

复用 Python 3.13.7、NumPy 2.3.5、SciPy 1.16.3、PyTorch 2.12.0 CPU、Matplotlib 3.10.8。参考与训练串行单线程。参考解、训练、事后评价分离；训练模块不能导入参考求解器。

适用旧方法：物理约束的精确边界、Dirac 分量消元、float64、残差最小二乘、独立网格、配置及原始失败记录。弃用束缚态归一化、实分量、宇称、节点先验、本征值训练、能隙限制及态间正交。

由于给定 E 后两个问题都是线性复边值问题，除常规多层 PINN 对照外，主协议拟采用随机特征 RBF 物理网络（PIELM 类）：固定随机隐藏层，训练复输出层，用同一方程残差的 SVD 最小二乘。明确它与全权重 Adam/L-BFGS PINN 的不同，种子变化表示隐藏特征变化。参数量分列训练/冻结参数；不可将此结果泛化为所有 PINN 的效果。

验收阈值在正式组前冻结：固定能量每个种子波形 L²<5e−4、R/T 绝对误差<5e−4、复振幅误差<5e−4、独立方程残差 RMS<5e−4、流变化及 R+T 偏差<5e−4、入射/出射边界误差<1e−9，且参考数值差至少小 100 倍。相位相对误差不用作小振幅验收。

所有试运行、未通过验收及预算结束记录保留，不按参考标签选样本或删种子。正式网络与训练预算可按物理残差开发调试后冻结；因此固定势问题不是盲测。条件网络只在给定训练能量网格使用方程残差，事后在未参加训练的能量评价。
